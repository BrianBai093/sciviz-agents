## Problems found and fixed in M3

All fixes are general; nothing is specific to a chart type.
- **Spend ledger corrupted by two parallel processes** (D41): fixed with an `fcntl` lock and unique temp files, the cost event is written first, and the ledger rebuilds itself from events.
- **The Critic demanded evidence a single view cannot show** (side-by-side placement, other viewport sizes, routing "proofs") (D42): views are now reviewed in isolation, against checkable criteria.
- **A race on `views.json` between parallel tool calls crashed a turn** (D43): atomic, locked updates, and `ToolErrorMiddleware` so a tool exception never aborts a run.
- **No way to retry a crashed turn cleanly**: added `run_turn(from_checkpoint=…)` (D44), used once to repair the demo session.
- **The single-agent ablation** is a supported mode (D40).
