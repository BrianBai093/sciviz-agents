**Problems found and fixed in this milestone**
1. **Job-id collision.** A continued session restarted job ids at `job1` and overwrote three stage-1 job folders. Ids are now unique per workspace. The two scripts the agent had stopped were rebuilt from J3 and verified against the event log; their logs are lost, and their `log.txt` says so.
2. **Writes the cell log did not see.** Agents also write files with the Deep Agents file tools, and a cell may then run them. A logging file backend now records these writes. For this session they were rebuilt from the checkpoints, and the final contents match the files on disk.
3. **Replay bookkeeping.** Cells read what the harness wrote (job scripts and logs, the cell log, gated figures). The export carries all of it, and the replay restores it in time order. Cells that cannot pass offline are reported, and the replay continues with their recorded artifacts.
4. **Overwritten turn records.** The second turn overwrote the first turn's lead report and API usage file. They are now archived per turn under `history/`.
